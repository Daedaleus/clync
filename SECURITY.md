# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via **GitHub's built-in private vulnerability reporting**:
Settings → Security → Report a vulnerability

Alternatively, send an e-mail to the address in the repository's contact info.

You can expect an initial response within 48 hours and a patch or mitigation plan within 14 days for confirmed vulnerabilities.

## Scope

- Backend API (authentication, authorisation, input validation)
- Frontend (XSS, data leakage, auth flows)
- Infrastructure / Docker images

## Out of scope

- Issues in third-party dependencies that have already been publicly disclosed
- Theoretical vulnerabilities with no practical impact
